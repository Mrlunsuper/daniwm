X11 · C + Xlib · Xinerama · Xft · XEmbed tray

user@daniwm:~$ daniwm 

Tiling + monocle window manager cho X11, viết thuần C trên Xlib. Kèm bar có tasklist kiểu Awesome, system tray, compositor nhẹ và launcher thay rofi — tất cả trong một repo, không dependency ngoài X headers.

Tính năng

Layout, bar, tray, rules, scratchpad — cấu hình bằng một file text.

Tiling + monocle

Master/stack với mfact/nmaster mỗi workspace, gaps trong/ngoài, drag-drop đổi chỗ kiểu bspwm.

5 workspace mặc định

Cấu hình 1–10; tên workspace, icon Nerd Font, style pill/underline/block. Workspace là global trên mọi monitor.

Bar + tasklist

CPU/MEM/BAT/VOL/clock qua Xft (UTF-8, tiếng Việt), task button click được, overflow gộp thành chip +N.

System tray

XEmbed _NET_SYSTEM_TRAY_Sn: nm-applet, volumeicon, cbatticon dock tự động; tự lấy lại selection khi owner thoát.

Multi-monitor

Xinerama per-monitor tiling, cửa sổ mới vào monitor con trỏ; RandR hotplug re-tile trực tiếp, không cần restart.

EWMH

_NET_* đầy đủ: client list, desktop, active window, struts, fullscreen, pager requests, _NET_WM_PID.

Rules & scratchpad

rule = class:title:float:ws[:layout]; Super+s bật terminal nổi giữa màn hình.

Restart tại chỗ

Super+Ctrl+r exec binary mới, giữ toàn bộ client, workspace, fullscreen và focus.

Compositor riêng

dani-comp: bóng đổ 7 lớp, fade-in 160ms, dim cửa sổ không focus, tôn trọng _NET_WM_WINDOW_OPACITY.

Launcher riêng

dani-run: drun fuzzy, favorite grid, power menu, calculator — thay rofi không cần config riêng.

HiDPI

scale = 1.5 nhân bar/border/gap/font, áp dụng live khi reload config.

Test headless

Hơn 35 suite Xvfb + xdotool trong test/: geometry, click delivery, focus model, strut, tray, compositor…

Build & cài

Một make ra ./daniwm, build với warning strict và fortified.

make                # build ./daniwm, ./dani-comp, ./dani-run
make check          # build + mọi suite headless (cần Xvfb, xterm, xdotool)
sudo make install   # /usr/local/bin + xsessions entry + share/daniwm/*.example
make install-user   # chỉ copy config + autostart.sh + run.config vào ~/.config/daniwm/

make install không ghi đè ~/.config/daniwm/config / autostart.sh / run.config — file đã có được giữ nguyên. Với DESTDIR (đóng gói) bước user-config bị bỏ qua; example nằm ở $(PREFIX)/share/daniwm/config.example, run.config.example, autostart.sh.example.

Phụ thuộc

X11 + Xinerama + Xrandr + Xft headers (Fedora: libX11-devel libXinerama-devel libXrandr-devel libXft-devel). dani-comp thêm Composite/Damage/Render/Fixes (libXcomposite-devel libXdamage-devel libXrender-devel libXfixes-devel, thường có sẵn cùng libX11-devel).

Chạy

Xephyr :1 & DISPLAY=:1 ./daniwm        # thử trong cửa sổ Xephyr
echo 'exec ~/daniwm/daniwm' >> ~/.xinitrc   # phiên thật
Autostart: daniwm chạy ~/.config/daniwm/autostart.sh nếu file đó có quyền thực thi.

Chuột trên bar

  • Click 1..N: đổi workspace (active = pill + chữ sáng, occupied = sáng + dot, urgent = rose).
  • Task button: trái = focus, giữa = đóng; cửa sổ urgent phát màu urgent.
  • Scroll trên workspace = ws trước/sau (wrap); scroll chỗ khác = volume; click trái module volume = mute (giữa/phải bất kỳ trên bar cũng mute).

Focus & stacking

Hover (sloppy) focus: rê chuột qua cửa sổ là activate mà không restack, nên cửa sổ float nhỏ lồng trong cửa sổ lớn vẫn với tới được. Click thường không bị WM ăn: WM quan sát qua XI2 raw events, nên click vào cửa sổ float đưa nó lên trước (click-to-raise) trong khi app vẫn nhận đủ press/release. Super+click vẫn là move/resize; Super+j/k cycle focus có raise.

Backend volume tự chọn: amixer → wpctl → pactl; phím laptop XF86Audio* dùng được ngay. Bar dùng Xft với per-glyph fallback (tiếng Việt, ký hiệu). Bên phải bar: icon Nerd Font + giá trị (CPU MEM BAT VOL DD/MM HH:MM), không có Nerd Font thì fallback C/M/B/V; battery/MUTE/CPU≥80%/MEM≥80% dùng màu urgent.

Config

~/.config/daniwm/config (hoặc $XDG_CONFIG_HOME/daniwm/config), dạng key = value, # là comment.

Thiếu file → dùng mặc định. Dòng sai → in stderr và bỏ qua, WM vẫn chạy. Reload (Super+Shift+r) áp dụng live các giá trị như scale, tên workspace, tray, màu bar.

Rules và binds

workspaces = 3
ws_names = Web Code Chat
rule = Gimp:*:float:*
bind = mod+3:ws3
bind+ = mod+a:spawn_menu
  • rule = class:title:float:ws[:layout] — * = bất kỳ, float = float|tile, ws 1-based ≤ workspaces, layout tuỳ chọn tile|monocle.
  • bind = mod+key:action — modifier mod/super/alt/ctrl/shift + X keysym. Hành động: focus_next/prev, zoom, ws_toggle, kill, tile/monocle/toggle, spawn_term/menu, mfact_dec/inc, nmaster_dec/inc, gap/gap_dec/gap_inc, bar, move_*, resize_w_dec/inc, resize_h_dec/inc, vol_up/down/mute, wsN, mvN, float, fullscreen, scratch, ws_rename, reload_config, restart, compositor, quit.
  • Dòng rule/bind đầu tiên thay bộ mặc định; bind+ để thêm. Bind wsN/mvN thiếu được tự điền theo workspaces (trừ khi combo đã bị bind khác chiếm).
  • Reload giữ mfact/nmaster live của từng workspace (giá trị trong config chỉ là mặc định lúc khởi động); giảm workspaces thì workspace dư gộp vào cái cuối.

Rule mặc định & scratchpad

Mặc định scratchpad, Gimp và mpv float. Super+s toggle xterm -name scratchpad (2/3 màn hình, giữa, lần đầu thì spawn). Lệnh scratch = tự đặt phải tạo cửa sổ có scratchpad trong class/name (vd alacritty --class scratchpad), nếu không toggle sẽ spawn liên tục thay vì toggle.

Compositor: dani-comp

Thay thế picom nếu bạn thích; cùng style với bar.

./dani-comp                             # bóng đổ + fade + dim mặc định
./dani-comp --no-shadow --no-fade
./dani-comp --dim 0.5                   # 0.5..1
# hoặc trong ~/.config/daniwm/config:
compositor = 1                          # daniwm tự spawn
# bind = mod+c:compositor               # toggle live
./test/test-comp.sh
  • Bóng đổ mềm 7 lớp kiểu picom, fade-in 160ms, làm mờ (dim) cửa sổ không focus qua inactive_dim (mặc định 0.92).
  • Tôn trọng _NET_WM_WINDOW_OPACITY (dùng được với transset), quảng bá _NET_WM_CM_Sn, tự nhường nếu picom đang chạy.
  • Giới hạn: double-buffered (không nháy), snapshot nền từ _XROOTPMAP_ID (root màu đơn sắc chỉ clear 1 lần khi nền đổi), cửa sổ shaped bị clip ở back buffer, không có vsync thật.

Launcher: dani-run

Thay rofi: drun fuzzy, favorite grid, power menu, calculator.

dani-run                # drun list dọc, fuzzy
dani-run --fav          # grid icon ứng dụng yêu thích (lọc được)
dani-run --power        # power menu (dùng lại UI fav)
dani-run --calc         # máy tính, Enter copy kết quả + in stdout
  • Quét /usr/share/applications + ~/.local/share/applications; Terminal=true được bọc bằng ${TERMINAL:-alacritty} -e.
  • Sắp xếp fuzzy + history ở ~/.cache/dani-run/history; hiện icon thật từ icon theme (PNG qua cairo nếu có, fallback glyph Nerd Font/chữ cái đầu; drun_icons = 0 để tắt).
  • Calculator hỗ trợ + - * / % ^, ngoặc, sqrt/sin/cos/tan/exp/abs/ln/log, pi/e.
  • Config ~/.config/daniwm/run.config (app = icon;name;cmd, power = ..., cols/lines/font; dòng app/power đầu tiên xoá mặc định). Phím: ↑↓←→/Ctrl+hjkl, Enter, Esc; scroll = trước/sau. Input drun không khớp app sẽ chạy như lệnh.

EWMH, monitor và restart

EWMH

_NET_SUPPORTED/CLIENT_LIST/ACTIVE_WINDOW, _NET_WM_PID (PID của WM trên supporting window, cũng quảng bá trong _NET_SUPPORTED), fullscreen qua _NET_WM_STATE, window-type float (dialog/utility/toolbar/splash/menu/dropdown/popup/tooltip/notification/combo/dnd + modal), dock (_NET_WM_WINDOW_TYPE_DOCK), struts (_NET_WM_STRUT/_NET_WM_STRUT_PARTIAL/_NET_WORKAREA) cho bar ngoài như Polybar/Tint2/Lemonbar, _NET_ACTIVE/CLOSE_WINDOW, workspace (_NET_NUMBER_OF_DESKTOPS/_NET_CURRENT_DESKTOP/_NET_WM_DESKTOP/_NET_DESKTOP_NAMES, kể cả pager view + move_to). Client message được xử lý trust-based theo spec: mọi client có thể yêu cầu close/move/focus (pager và wmctrl dựa vào điều này), daniwm không kiểm tra sender.

Monitor

Tiling theo từng monitor qua Xinerama (fallback: toàn màn hình); cửa sổ mới vào monitor có con trỏ; bar ở monitor 0; workspace là global; margin strut từng monitor tính tự động.

Restart

Super+Ctrl+r (action restart) exec binary mới đè lên process đang chạy — mọi client sống sót, giữ workspace (_NET_WM_DESKTOP), fullscreen, desktop hiện tại, focus và scratchpad đang park. Trạng thái float và layout/mfact/nmaster theo workspace reset về mặc định. Watcher bên ngoài phát hiện re-exec qua stamp _DANIWM_HEARTBEAT trên root (PID giữ nguyên qua exec, X server có thể tái dùng window ID).

Tray

XEmbed (_NET_SYSTEM_TRAY_Sn) ở cạnh phải bar — nm-applet --indicator, volumeicon, cbatticon tự dock; divider dọc tách tray khỏi clock; click vào vùng tray không lọt sang workspace; selection bị bỏ trống sẽ được lấy lại tự động. tray = 0 để tắt (reload live). Chỉ XEmbed cổ điển — app StatusNotifier/AppIndicator cần cầu snixembed.

Kiểm thử headless

Chạy được từ Wayland; cần xorg-x11-server-Xvfb (+ xterm, xdotool).

./test/verify.sh     # một suite
./test/run-all.sh    # tất cả suite
make check           # build + check-ai + toàn bộ suite

Dựng Xvfb 1280x800, spawn 3 xterm qua Super+Return, assert geometry bằng xdotool (master 14,38,681x744, stack x=707, monocle 14,38,1248x744, fullscreen 0,0,1280x800), đi qua gaps/ws/move-fullscreen/scratchpad và chụp từng bước vào test/shots/.

test/run-all.sh chạy ~38 suite: verify config kill mouse workspaces strut randr tray restart tasklist comp nested-float click-delivery click-raise-float focus-steal ghost-unmap wm-state focus-model noinput takefocus remap-steal xerr direct-state urgency ws-storm kill-stamp clamp-float reload-hidden supported focus-time click-focus restart-withdrawn fs-offws vol-hang gap-cap rename-stuck tiled-restack scratch-focus transient-parent run. make check-ai chạy riêng suite của dani-ai, không cần X server hay API key thật.

Danh sách suite: lấy trực tiếp từ test/run-all.sh trong repo. Chạy ./test/run-all.sh để xem kết quả PASS/FAIL thực tế trên máy bạn — trang này không tự chạy test.
