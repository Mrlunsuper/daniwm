Chat AI ngay trong terminal. Không framework, không dependency, không GUI — một file Python, một API key, và tool use để đọc file / chạy lệnh. Bạn có thể tắt hoặc chặn từng tool khi cần.

Bắt đầu Cách dùng Tool use Bảo mật

Tính năng

Nhỏ, nhanh, chạy ở đâu có Python 3 là chạy được.

Stream mặc định

Token hiện ngay khi tới, markdown có màu trong TTY, giữ text thô khi pipe. Stream phải kết thúc bằng [DONE].

BYOK

Mang key của bạn: OpenAI, DeepSeek, Ollama, LM Studio, FreeLLMAPI, Vilao… mọi endpoint OpenAI-compatible.

Profile provider

--profile pin base/model + khai báo capability (tools, vision, stream, token parameter). Không lưu key trong JSON.

Paste ảnh

Ctrl+V đọc clipboard: ảnh PNG/JPEG/WebP/GIF thành [Ảnh 1], text chèn tại con trỏ (bracketed paste).

Tool use

Đọc/tìm/ghi/sửa file, tạo thư mục, đọc URL và Git status; chặn theo tên/glob, deny-path, write-path. run_command cần opt-in.

Session & history

Mỗi phiên một ID session-<uuid>.json, autosave, --continue, /save, ghi atomic

quyền 0600, khoá bằng flock.

Diff & undo

/diff xem thay đổi file của lượt gần nhất, /undo khôi phục có preflight (từ chối nếu bạn đã sửa file).

Chế độ pipe

Tích hợp daniwm

Một file, không cài

Chỉ Python 3 stdlib: readline, urllib, json. Không pip, không venv.

Cài đặt

Chỉ cần Python 3. Muốn paste ảnh thì thêm xclip (X11) hoặc wl-paste (Wayland).

# trong repo daniwm
chmod +x dani-ai
mkdir -p ~/.local/bin
ln -s "$PWD/dani-ai" ~/.local/bin/dani-ai   # hoặc copy thẳng

# key: 3 dòng — key, base URL, model (dòng 2, 3 tuỳ chọn)
mkdir -p ~/.config/daniwm
cat > ~/.config/daniwm/ai.key <<'K'
sk-...
https://api.deepseek.com/v1
deepseek-chat
K
chmod 600 ~/.config/daniwm/ai.key

Kiểm tra nhanh

dani-ai --version
dani-ai --show-config          # in ra cấu hình đã resolve (tools, root, lỗi manifest)
dani-ai models                 # danh sách model từ /models
dani-ai tools                  # liệt kê tool builtin + custom
dani-ai "xin chao"              # thử request đầu tiên

Đặt dani-ai ở đâu cũng được — nó chỉ dùng module chuẩn, không import gì trong repo. Nếu ~/.local/bin chưa có trong PATH: export PATH="$HOME/.local/bin:$PATH".

Cấu hình

Dùng file cấu hình, biến môi trường, flag hoặc profile. Flags có ưu tiên cao nhất.

API key, endpoint và model

  • Key: --api-key → DANI_AI_API_KEY → OPENAI_API_KEY → DEEPSEEK_API_KEY → FREELLMAPI_API_KEY → VILAO_API_KEY → dòng 1 của ai.key.
  • Endpoint: --api-base → DANI_AI_API_BASE → OPENAI_API_BASE → dòng 2 của ai.key → mặc định.
  • Model: --model → DANI_AI_MODEL → dòng 3 của ai.key → mặc định.

Mặc định dùng https://api.openai.com/v1 và gpt-4o-mini. Key lấy từ DEEPSEEK_API_KEY tự chọn endpoint DeepSeek nếu chưa đặt endpoint; endpoint DeepSeek mặc định chọn deepseek-chat nếu chưa đặt model.

export DANI_AI_API_BASE="https://api.deepseek.com/v1"
export DANI_AI_MODEL="deepseek-chat"
# Lưu key trong ai.key như phần Cài đặt, tránh ghi key vào lịch sử shell.
dani-ai --show-config

System prompt

Thứ tự: --system → --system-file → DANI_AI_SYSTEM_FILE → ~/.config/daniwm/ai.system.

# Chạy trong repo daniwm
cp ai.system.example ~/.config/daniwm/ai.system
dani-ai --system "Trả lời ngắn gọn bằng tiếng Việt." "Giải thích X11"

Profile provider và capabilities

Profile là opt-in: không dùng --profile thì key/base/model vẫn resolve như trên. Tạo ~/.config/daniwm/ai.profiles.json (nên chmod 600):

{
  "version": 1,
  "profiles": {
    "openai-mini": {
      "base": "https://api.openai.com/v1",
      "model": "gpt-4o-mini",
      "key_env": "OPENAI_API_KEY",
      "capabilities": {
        "tools": true,
        "vision": true,
        "stream": true,
        "token_parameter": "max_completion_tokens"
      }
    }
  }
}
export OPENAI_API_KEY='...'
dani-ai --profile openai-mini --show-config
dani-ai --profile openai-mini chat
dani-ai --profile openai-mini --profiles-file /path/to/profiles.json chat
  • Profile pin endpoint, model và tên biến môi trường chứa key; không fallback sang key env/`ai.key` khác. Không lưu key trong JSON.
  • --api-base/--api-key bị từ chối khi dùng profile; --model chỉ chấp nhận nếu trùng model profile.
  • Capabilities khai báo thủ công, không tự probe: tools:false tắt runner, stream:false chọn non-stream, vision:false từ chối ảnh kể cả ảnh trong session resume.
  • Token parameter: max_tokens, max_completion_tokens hoặc null (không hỗ trợ --max-tokens).
  • /model bị khoá trong profile; session context ghi profile/model/capabilities (không có key), mismatch cần --trust-session.
  • Request bị ràng buộc trong base của profile; redirect khác origin luôn bị chặn. Chưa có auto-discovery hay đổi profile giữa REPL.
Đường dẫn: DANI_AI_KEY_FILE đổi vị trí file key. Các đường dẫn cấu hình mặc định dùng $XDG_CONFIG_HOME/daniwm nếu biến này được đặt, thay cho ~/.config/daniwm.

Cách dùng

Hỏi một lần, chat tương tác hoặc đưa nội dung qua stdin.

# Hỏi một lần
dani-ai "Giải thích sự khác nhau giữa X11 và Wayland"

# Chat tương tác
dani-ai chat

# Tóm tắt stdin, không cho model gọi tool
cat README.md | dani-ai --no-tools "Tóm tắt nội dung này"

# Lưu câu trả lời dạng text, không màu
dani-ai --no-tools "Viết checklist cài Linux" > checklist.txt

# Danh sách và tiếp tục hội thoại
dani-ai history
dani-ai chat --continue
dani-ai chat --continue ten-phien
dani-ai --continue last "câu hỏi tiếp"   # single-shot, gửi cả context đã lưu

# Chạy như một lệnh khác dùng key/endpoint nào
dani-ai --check            # (xem --help)
daniwm: dùng Super+Shift+a để mở AI theo cấu hình WM. Trong terminal bất kỳ, chạy dani-ai chat.

REPL

Trong dani-ai chat, dùng lệnh bắt đầu bằng dấu /.

/save [tên]Lưu phiên; bỏ tên để AI gợi ý tên. Từ chối tên đã tồn tại thay vì ghi đè.
/resume [tên]Mở phiên đã lưu (tạo nhánh ID mới, không sửa phiên nguồn); bỏ tên để chọn từ danh sách.

/clearXoá màn hình và bắt đầu hội thoại mới.

/compact [N]Giữ N lượt user gần nhất (mặc định 4) + system + tool của các lượt đó; bỏ trọn lượt cũ, không tạo summary.
/contextSố message, tool result và dung lượng JSON — không phải token usage.

/diff, /undoDiff lượt gần nhất; undo có preview + confirm, khôi phục nội dung/mode cũ, xoá file mới do AI tạo.

/stream on|offBật/tắt streaming.

Tab hoàn thành lệnh, phím ↑ gọi lại dòng đã nhập, Ctrl+D thoát khi dòng nhập trống. Terminal hiện spinner Đang chờ phản hồi… cho tới khi có nội dung trả lời; pipe không có spinner.

Lỗi API/timeout hoặc Ctrl+C khi đang request không đóng REPL. Lượt lỗi chưa chạy tool bị loại khỏi context (nhưng giữ trong RAM để /retry); nếu đã có tool call thì journal được giữ và cần kiểm tra workspace trước khi thử lại.

Session, export và private mode

Mỗi hội thoại một file riêng; last.json chỉ là checkpoint publish gần nhất.

Session ID và nhiều phiên cùng lúc

  • Mỗi REPL / cơ chế tool checkpoint dùng session-<uuid>.json riêng. ID in ra khi thoát, dùng với --continue ID.
  • last.json là bản sao checkpoint vừa publish gần nhất, không phải ID cố định của một REPL: khi chạy nhiều phiên, --continue có thể mở phiên khác — dùng ID cụ thể để chọn đúng.
  • Ghi checkpoint/last và /save được serialize bằng flock trên .history.lock; lock tự nhả khi process thoát/crash.
  • Lock là advisory cho các process dani-ai hợp tác trên filesystem hỗ trợ flock (Linux/local), không chống chương trình sửa file bên ngoài. Chưa có retention/cleanup tự động.

Export / delete (local, không cần API key)

dani-ai history                                      # xem tên snapshot
dani-ai history export TEN json ~/chat-backup.json    # JSON giữ metadata/messages
dani-ai history export TEN md ~/chat-backup.md        # Markdown để đọc/lưu trữ
dani-ai history delete TEN CONFIRM                    # xoá đúng snapshot TEN
  • TÊN là stem không có .json, chỉ chữ/số/_/-; dùng được last, tên /save hoặc session-<uuid>. Thiếu CONFIRM thì không xoá.
  • Export create-only, publish atomic, mode 0600; từ chối ghi đè file/symlink. Markdown giữ message JSON trong indented blocks (gồm tool call/result và image payload), không phải định dạng import.
  • Export chứa dữ liệu riêng tư: system prompt, context root/provider, toàn bộ tool output và attachments — không scrub secret.
  • Delete chỉ unlink một snapshot dưới history lock, từ chối symlink/hardlink/JSON không có messages. Không xoá alias/last theo session_id, exports, readline history hay workspace. Không secure erase.

Private mode

  • dani-ai chat --no-history: không đọc/ghi readline history, không autosave, không ghi tool checkpoint; /save, /resume, /export, /delete bị tắt và không dùng chung với --continue.
  • Tool call/result vẫn giữ trong bộ nhớ khi lỗi, nhưng crash/kill sẽ không có journal trên đĩa để phục hồi.
  • Đây KHÔNG phải chế độ offline hay sandbox: provider vẫn nhận prompt, tool vẫn có thể ghi workspace theo permission policy, shell/terminal bên ngoài vẫn có thể lưu log.
  • File session là plaintext (0600), không mã hoá. Readline history cũ không tự được scrub.

Tool use

Bật mặc định. Endpoint và model cần hỗ trợ function calling.

ToolChức năng và giới hạn
list_filesLiệt kê thư mục, không đệ quy, tối đa 200 mục.
read_fileĐọc file UTF-8 tối đa 2 MiB; phân trang offset/limit (tối đa 64.000 ký tự), báo truncated và next_offset.
search_textTìm chuỗi nguyên văn trong một file, tối đa 100 dòng khớp.
find_filesTìm đệ quy theo glob tên file (vd *.py); tôn trọng ignore mặc định và .aiignore; báo số entry ignored.
search_filesTìm chuỗi literal đệ quy, trả path:line:text; mỗi trang tối đa 2.000 entry / 100 kết quả / 16.000 ký tự, có next_cursor.
make_directoryTạo thư mục và các cha còn thiếu (mode 700) trong tool root; từ chối symlink.
write_fileTạo file mới, không ghi đè; thư mục cha phải có sẵn; mode 600.
edit_fileThay đoạn text khớp chính xác một lần; ghi atomic, giữ quyền file.
fetch_urlGET link công khai http(s), trả text + title + status (20 giây, 2 MiB, 16.000 ký tự); chặn host private/loopback/link-local, URL có credential, file binary; kiểm tra lại mỗi redirect.
git_statusBranch và trạng thái repo chứa tool root; không cần shell, không ghi index/commit, bỏ qua submodule.
run_commandTắt mặc định; bật bằng --allow-shell hoặc /shell on. Shell toàn quyền user, không sandbox; timeout 30 giây, đầu ra tối đa 64 KiB.

Cả hai tool scan (find_files/search_files) trả next_cursor: khi khác null, gọi lại cùng tool/path/pattern (hoặc query) kèm cursor: "..." để tiếp tục. Cursor là opaque, single-use, chỉ trong process, tối đa 4 scan đang dở, idle TTL 120 giây; reset/new/clear, resume/đổi root và thoát REPL đều đóng cursor. Đây không phải snapshot: filesystem thay đổi giữa các trang có thể làm kết quả thiếu/thừa/stale.

Search bỏ qua file > 64 KiB, file binary/không phải UTF-8, không theo symlink, không đọc hardlink hay đường dẫn ẩn/nhạy cảm. Ghi/sửa/search giới hạn 64 KiB UTF-8/file; read_file tới 2 MiB; mọi đường dẫn tính từ tool root.

# Chỉ đọc project, chặn shell và không nạp custom tools
dani-ai --tool-root "$PWD" --block-tool run_command --no-custom-tools chat

# Chỉ đọc file/search/git status
dani-ai --permissions read-only chat

# Tắt toàn bộ tools
dani-ai --no-tools "Giải thích tiling WM"

# Chặn theo tên hoặc glob (quote để shell không tự mở rộng)
dani-ai --block-tool 'btc_*' chat

# Shell opt-in (KHÔNG sandbox)
dani-ai chat --allow-shell

Blocklist

File ~/.config/daniwm/ai.tools.blocklist chứa mỗi dòng một tên hoặc glob; dùng # để ghi chú. Chọn file khác bằng --tool-blocklist, thêm bằng --block-tool (lặp lại được, cộng dồn). Blocklist đọc khi khởi động — sửa xong phải mở lại CLI. Tool bị chặn không xuất hiện trong request; nếu model vẫn gọi thì executor từ chối.

# Tắt shell trước khi giới hạn truy cập file
run_command
read_file
search_*
# Dùng * để chặn tất cả
Không phải sandbox: --tool-root và các tool file không cho đường dẫn tuyệt đối, .., symlink, hardlink, file ẩn và một số tên secret/key phổ biến — nhưng run_command và custom tools vẫn truy cập được ngoài root. Shell chạy bằng quyền của bạn; API key và biến môi trường có tên secret/token/password không được truyền cho shell, nhưng shell vẫn đọc được file của bạn. Chặn run_command hoặc dùng --no-tools khi không tin nội dung đầu vào.

Quyền và chính sách

Permission mode, giới hạn path/domain, budget và deadline của một lượt.

Permission mode

ModeHành vi
ask (mặc định)Hiện diff trước khi ghi file; hỏi trước mkdir/network/shell/custom tool. Đọc file local không hỏi. Không có TTY thì tự từ chối.
read-onlyChỉ đọc file/search/git status; chặn cả fetch_url, shell và custom tool.
workspace-writeGhi trong workspace và fetch URL không hỏi; custom tool vẫn tôn trọng confirm.

--yes-tools tự đồng ý prompt nhưng không vượt blocklist/read-only và không bật shell.

Path / domain policy

dani-ai chat --deny-path 'private' --deny-path '*backup*' \
  --write-path 'src' --write-path 'src/*' --allow-domain docs.python.org
  • --deny-path GLOB: chặn đọc/ghi và ẩn entry khỏi list/find/search; thắng cả write allowlist, áp dụng cả với --include-ignored và --yes-tools.
  • Glob là fnmatch case-sensitive trên path root-relative đã normalize; * match được cả / (không phải gitignore). Ancestor bị deny thì cả cây con bị deny.
  • --write-path: write/edit/mkdir chỉ được ghi path khớp glob; make_directory kiểm tra từng parent.
  • --allow-domain HOST: so khớp chính xác hostname (IDNA/case normalized), không scheme/port/wildcard, không tự cho subdomain; kiểm tra trước DNS và mỗi redirect.
  • Preset ask hỏi một lần cho mỗi web origin trong session (kể cả origin mới qua redirect). Approval mất khi new/reset/clear/resume hoặc đổi root.
  • Đây không phải sandbox/DLP: process shell/custom vẫn ra ngoài policy; git_status là metadata repo, không lọc theo deny (chặn bằng --block-tool git_status).

Budget của một lượt

  • Mặc định tối đa 64 tool call và 1 MiB tool-result UTF-8 mỗi lượt; đổi bằng --max-tool-calls N / --max-tool-output BYTES.
  • Batch vượt call budget sẽ không chạy. Output chỉ biết sau khi tool chạy: nếu vượt, ghi lại tool đã chạy, dừng các call còn lại, không tự retry, không rollback file.
  • --turn-timeout SECONDS (mặc định 300) là budget cooperative chung cho API/tool rounds, retry sleeps và thời gian chờ approval. Không phải hard wall-clock: DNS/connect/header, filesystem I/O, history lock và approval prompt có thể giữ process quá hạn.
  • --http-retries N (0..3, mặc định 0) chỉ retry 429/502/503/504 trước khi đọc body; backoff 1/2/4s hoặc Retry-After. Không retry transport error, body/JSON lỗi, partial stream, tool/custom/web.

Giới hạn transport

  • API JSON/stream tối đa 16 MiB; mỗi dòng SSE 1 MiB, tối đa 100.000 dòng; nội dung answer 2.097.152 ký tự; request/session 32 MiB; stdin 2.097.152 ký tự. Vượt budget báo lỗi, không lưu partial answer.
  • --timeout là budget tính từ lúc bắt đầu request, đọc body theo thời gian còn lại (chặn server nhỏ giọt). DNS và pha kết nối/header vẫn phụ thuộc timeout nền tảng.
  • Redirect khác origin (kể cả HTTPS → HTTP) bị chặn để tránh gửi API key sang endpoint khác. HTTP vẫn hỗ trợ cho local server; remote nên dùng HTTPS.

Custom tools

Mỗi tool = 1 manifest <tên>.json + 1 script bất kỳ trong ~/.config/daniwm/ai.tools/.

dani-ai tools                       # liệt kê tool builtin + custom
dani-ai --tools-dir ./ai.tools tools
dani-ai --no-custom-tools chat      # chỉ dùng builtin
dani-ai --yes-tools chat            # tự đồng ý tool có confirm
{
  "name": "btc_market",
  "description": "Read public Binance USD-M futures data (ticker, klines, funding, OI, long/short). Read-only.",
  "command": ["python3", "{manifest_dir}/btc_market.py"],
  "timeout": 30,
  "output_limit": 131072,
  "confirm": false,
  "parameters": {
    "type": "object",
    "properties": {"symbol": {"type": "string"}},
    "required": [],
    "additionalProperties": false
  }
}
  • Arguments được validate theo parameters (JSON Schema con) rồi gửi qua stdin dạng JSON — không qua shell, không interpolate. Sai schema thì không chạy lệnh.
  • command là argv list, chạy trực tiếp (không qua /bin/sh) với cwd = tool root; {manifest_dir} được thay bằng thư mục chứa manifest.
  • Tool in JSON/text ra stdout; stderr giữ riêng (tối đa 4 KiB). Exit code ≠ 0 hoặc stdout rỗng → trả error.
  • Biến môi trường khớp *API_KEY*, *TOKEN*, *SECRET*, *PASSWORD*, *CREDENTIAL* không được truyền; có thêm DANI_TOOL_NAME, DANI_TOOL_ROOT.
  • timeout mặc định 30s (tối đa 120s), output_limit 256..262144 bytes; vượt thì kill process group và trả error.
  • confirm: true hỏi y/N trên TTY trước khi chạy; không có TTY thì từ chối (hoặc tự đồng ý với --yes-tools).
  • Tên tool khớp ^[a-z][a-z0-9_]{1,40}$, không trùng builtin, tối đa 32 custom tool. Manifest lỗi bị bỏ qua và báo trong --show-config (tool_manifest_error).
  • --block-tool/blocklist áp dụng cho cả custom tool (glob theo tên).

Tool mẫu: btc_market

mkdir -p ~/.config/daniwm/ai.tools
cp ~/daniwm/ai.tools/* ~/.config/daniwm/ai.tools/
dani-ai "Lay du lieu BTC 4h va nhan xet xu huong"   # model tự gọi btc_market
  • Dữ liệu công khai Binance USD-M futures: ticker 24h, klines OHLCV + thống kê cửa sổ, funding rate, open interest, long/short ratio. Chỉ đọc, không cần API key, không đặt lệnh.
  • long_pct/short_pct theo phần trăm (0..100). Long/short period khác kline interval: 1m → 5m, 8h → 6h, 1w → 1d; period thực tế nằm trong long_short.period.
  • Giới hạn 2 MiB/response, budget đọc 24s trong process timeout 30s; trả partial + errors nếu một section lỗi/hết budget, giữ section đã lấy.
  • Timestamp là unix milliseconds; ticker/funding/OI có age_seconds khi nguồn trả timestamp; nến có close_time/is_closed, nến cuối có thể chưa đóng.
  • annualized_pct chỉ là ngoại suy giả định funding 8 giờ và rate không đổi — không phải lịch funding đã xác minh, dự báo hay lợi nhuận.
  • Multi-timeframe opt-in: intervals 1..4 khung duy nhất phải chứa interval chính, tổng len(intervals)*limit ≤ 400; timeframes[i] có candles/window/closed_window, lỗi từng khung nằm trong errors[].interval.
  • open_interest_history (opt-in) lấy lịch sử OI tháng gần nhất, trả samples + % thay đổi đầu-cuối; dưới hai mẫu hoặc mẫu đầu bằng 0 thì change là null.
{"interval":"1h","intervals":["4h","1h","15m"],"limit":100,"include":["klines","open_interest_history"]}
Đọc số liệu: OI snapshot không kết luận được xu hướng OI; % thay đổi chỉ mô tả cửa sổ mẫu, không phải tín hiệu mua/bán hay cam kết lợi nhuận.

Paste ảnh

Dán ảnh clipboard trực tiếp vào dòng nhập REPL bằng Ctrl+V.

  1. Cài xclip trên X11 hoặc công cụ wl-paste (gói wl-clipboard) trên Wayland.
  2. Chạy dani-ai chat với model có hỗ trợ vision (hoặc profile khai báo "vision": true).
  3. Copy ảnh, nhấn Ctrl+V: dòng nhập hiện placeholder như [Ảnh 1] — có thể paste nhiều ảnh.
  4. Nhập câu hỏi về ảnh rồi nhấn Enter để gửi. Xoá marker ảnh trước khi Enter để bỏ đính kèm.

Hỗ trợ PNG, JPEG, WebP và GIF; mỗi ảnh tối đa 10 MiB; model/API phải hỗ trợ vision và image_url kiểu OpenAI. Nếu clipboard là text, nội dung được chèn tại con trỏ — GNU readline bật bracketed paste nên text nhiều dòng (kể cả newline cuối) chỉ để xem/sửa, không tự gửi.

Lưu ý: Ctrl+Shift+V vẫn là paste text của terminal, không phải phím paste ảnh. Ảnh được gửi đến API khi Enter và lưu trong session (base64, file 0600); không gửi ảnh chứa thông tin nhạy cảm nếu chưa kiểm tra nhà cung cấp.

Bảo mật

Key của bạn, dữ liệu của bạn — kiểm tra quyền truy cập trước khi bật tools.

  • Đặt quyền 600 cho ai.key và ai.profiles.json; không commit key hoặc file lịch sử vào Git.
  • Nội dung chat, ảnh và kết quả tool được gửi đến nhà cung cấp API đang cấu hình. Ưu tiên HTTPS cho endpoint từ xa; redirect khác origin bị chặn.
  • History/readline history/session ghi atomic (thư mục 0700, file 0600) nhưng là plaintext, không mã hoá. Xoá hoặc bảo vệ file nếu chứa dữ liệu nhạy cảm.
  • Nội dung file, trang web hoặc đầu ra lệnh có thể chứa chỉ dẫn độc hại (prompt injection). Không coi chúng là chỉ dẫn đáng tin.
  • fetch_url chỉ GET, không gửi API key; chặn host private/loopback/link-local/reserved và kiểm tra lại từng redirect (tối đa 5), HTTPS → HTTP bị từ chối. Không có JavaScript/cookie/đăng nhập.
  • run_command có thể sửa/xoá file và truy cập mạng. Không chạy dani-ai bằng root; dùng --no-tools khi chỉ cần hỏi đáp.
  • Chỉ cài custom tools đã kiểm tra mã nguồn; tránh --yes-tools với tool chưa tin cậy. File profile là cấu hình tin cậy: người sửa file có thể đổi nơi nhận key.
  • Control sequence từ API bị lọc khi hiển thị TTY; pipe giữ raw text. --no-color/NO_COLOR chỉ tắt màu, không tắt bộ lọc TTY.

Sự cố

Bắt đầu với dani-ai --show-config để kiểm tra endpoint, model, tools và nguồn cấu hình.

Không tìm thấy lệnh dani-ai

Kiểm tra symlink, quyền thực thi và thêm ~/.local/bin vào PATH. Trong repo có thể chạy trực tiếp ./dani-ai --version.

Thiếu key hoặc lỗi 401 / 403

Kiểm tra dòng đầu của ai.key, key còn hiệu lực và quyền truy cập model. Biến môi trường hoặc flags có thể đang ghi đè file key. Khi dùng --profile, key chỉ lấy từ biến mà profile chỉ định trong key_env — không fallback sang ai.key.

Lỗi 404 hoặc model không tồn tại

Kiểm tra base URL (thường kết thúc bằng /v1, không thêm /chat/completions). Chạy dani-ai models để lấy tên model nếu provider hỗ trợ.

API không hỗ trợ tools hoặc streaming

Thử dani-ai --no-tools --no-stream "Xin chào", hoặc khai báo "tools": false / "stream": false trong profile. Không phải endpoint OpenAI-compatible nào cũng hỗ trợ đủ.

Stream bị lỗi hoặc cắt giữa chừng

Stream phải kết thúc bằng [DONE]. JSON lỗi, error event hoặc stream bị cắt sẽ báo lỗi; text đã hiện không được lưu như câu trả lời hoàn chỉnh. finish_reason: length/content_filter cũng báo lỗi, không lưu vào history.

Session không resume được

Session v2 ghi project root và API base. Resume khác project/provider, hoặc phiên cũ thiếu metadata, sẽ bị từ chối — chỉ dùng --trust-session sau khi đã kiểm tra nội dung và nguồn gốc. /base không đổi provider giữa chat; hãy khởi động lại với endpoint và key tương ứng.

Timeout hoặc lỗi 429

Tăng --timeout nếu API chậm, tăng --turn-timeout nếu lượt có nhiều tool; bật --http-retries 1..3 nếu gặp 429/502/503/504 (lưu ý provider có thể vẫn tính phí cho POST retry).

/undo bị từ chối

Undo preflight đòi nội dung và identity khớp trạng thái AI để lại, không symlink/hardlink. Nếu bạn đã sửa file sau đó, hoặc trong lượt đã có shell/custom tool, undo bị từ chối để không ghi đè — hãy dùng Git/backup.

Không paste được ảnh

Kiểm tra xclip / wl-paste, clipboard đang chứa dữ liệu ảnh và terminal không chặn Ctrl+V. Cần model hỗ trợ vision (hoặc vision: true trong profile); ảnh quá 10 MiB cần giảm kích thước trước.

Tool không xuất hiện hoặc bị từ chối

Kiểm tra --no-tools, blocklist và thư mục manifest (--show-config in tool_manifest_error). Tool confirm: true bị từ chối khi không có TTY để hỏi; chỉ dùng --yes-tools khi đã kiểm tra tool. Kiểm tra cả --deny-path/--write-path nếu file bị chặn.
