Chat AI ngay trong terminal. Không framework, không dependency, không GUI — một file Python, một API key, và tool use để đọc file / chạy lệnh. Bạn có thể tắt hoặc chặn từng tool khi cần.

Cài đặt

Chỉ cần Python 3. Muốn paste ảnh thì thêm xclip (X11) hoặc wl-paste (Wayland).

# trong repo daniwm
chmod +x dani-ai
mkdir -p ~/.local/bin
ln -s "$PWD/dani-ai" ~/.local/bin/dani-ai   # hoặc copy thẳng

# key: 3 dòng — key, base URL, model (dòng 2, 3 tuỳ chọn)
mkdir -p ~/.config/daniwm
cat > ~/.config/daniwm/ai.key <<'K'
sk-...
https://api.deepseek.com/v1
deepseek-chat
K
chmod 600 ~/.config/daniwm/ai.key

Kiểm tra nhanh

dani-ai --version
dani-ai 0.1.0
dani-ai --show-config          # in ra cấu hình đã resolve
dani-ai models                 # danh sách model từ /models
dani-ai "xin chao"              # thử request đầu tiên

Đặt dani-ai ở đâu cũng được — nó chỉ dùng module chuẩn, không import gì trong repo. Nếu ~/.local/bin chưa có trong PATH: export PATH="$HOME/.local/bin:$PATH".

Cấu hình

Dùng file cấu hình, biến môi trường hoặc flags. Flags có ưu tiên cao nhất.

API key, endpoint và model

  • Key: --api-key → DANI_AI_API_KEY → OPENAI_API_KEY → DEEPSEEK_API_KEY → FREELLMAPI_API_KEY → VILAO_API_KEY → dòng 1 của ai.key.
  • Endpoint: --api-base → DANI_AI_API_BASE → OPENAI_API_BASE → dòng 2 của ai.key → mặc định.
  • Model: --model → DANI_AI_MODEL → dòng 3 của ai.key → mặc định.

Mặc định dùng https://api.openai.com/v1 và gpt-4o-mini. Key lấy từ DEEPSEEK_API_KEY tự chọn endpoint DeepSeek nếu chưa đặt endpoint; endpoint DeepSeek mặc định chọn deepseek-chat nếu chưa đặt model.

export DANI_AI_API_BASE="https://api.deepseek.com/v1"
export DANI_AI_MODEL="deepseek-chat"
# Lưu key trong ai.key như phần Cài đặt, tránh ghi key vào lịch sử shell.
dani-ai --show-config

System prompt

Thứ tự: --system → --system-file → DANI_AI_SYSTEM_FILE → ~/.config/daniwm/ai.system.

# Chạy trong repo daniwm
cp ai.system.example ~/.config/daniwm/ai.system
dani-ai --system "Trả lời ngắn gọn bằng tiếng Việt." "Giải thích X11"
Đường dẫn: DANI_AI_KEY_FILE đổi vị trí file key. Các đường dẫn cấu hình mặc định dùng $XDG_CONFIG_HOME/daniwm nếu biến này được đặt, thay cho ~/.config/daniwm.

Cách dùng

Hỏi một lần, chat tương tác hoặc đưa nội dung qua stdin.

# Hỏi một lần
dani-ai "Giải thích sự khác nhau giữa X11 và Wayland"

# Chat tương tác
dani-ai chat

# Tóm tắt stdin, không cho model gọi tool
cat README.md | dani-ai --no-tools "Tóm tắt nội dung này"

# Lưu câu trả lời dạng text, không màu
dani-ai --no-tools "Viết checklist cài Linux" > checklist.txt

# Danh sách và tiếp tục hội thoại
dani-ai history
dani-ai chat --continue
dani-ai chat --continue ten-phien
daniwm: dùng Super+Shift+a để mở AI theo cấu hình WM. Trong terminal bất kỳ, chạy dani-ai chat.

REPL

Trong dani-ai chat, dùng lệnh bắt đầu bằng dấu /.

LệnhChức năng
/helpHiện hướng dẫn lệnh.
/model [tên]Đặt model; không có tên thì lấy danh sách để chọn.
/base [url]Đổi hoặc xem endpoint hiện tại.
/system [nội dung]Đặt system prompt; không có nội dung thì xóa prompt.
/save [tên]Lưu phiên; bỏ tên để AI gợi ý tên.
/resume [tên]Mở phiên đã lưu; bỏ tên để chọn từ danh sách.
/reset, /newXóa ngữ cảnh hội thoại hiện tại, giữ system prompt.
/clearXóa màn hình và bắt đầu hội thoại mới.
/stream on|offBật/tắt streaming.
/color on|offBật/tắt màu markdown.
/quit, /exit, /qThoát chat.

Tab hoàn thành lệnh, phím ↑ gọi lại dòng đã nhập, Ctrl+D thoát khi dòng nhập trống.

Phiên được tự lưu; file hội thoại và lịch sử nhập nằm trong ~/.config/daniwm/ai-history, ghi atomic với quyền 0600.

Tool use

Bật mặc định. Endpoint và model cần hỗ trợ function calling.

ToolChức năng và giới hạn
list_filesLiệt kê thư mục, không đệ quy, tối đa 200 mục.
read_fileĐọc file UTF-8, tối đa 64 KiB.
search_textTìm chuỗi nguyên văn trong một file, tối đa 100 dòng khớp.
run_commandChạy lệnh qua /bin/sh, timeout 30 giây, đầu ra tối đa 64 KiB.
 
# Chỉ đọc project, chặn shell và không nạp custom tools
dani-ai --tool-root "$PWD" --block-tool run_command --no-custom-tools chat

# Tắt toàn bộ tools
dani-ai --no-tools "Giải thích tiling WM"

# Chặn theo tên hoặc glob (quote để shell không tự mở rộng)
dani-ai --block-tool 'btc_*' chat

Blocklist và custom tools

File ~/.config/daniwm/ai.tools.blocklist chứa mỗi dòng một tên hoặc glob; dùng # để ghi chú. Chọn file khác bằng --tool-blocklist.

Custom tools được nạp từ các manifest *.json trong ~/.config/daniwm/ai.tools. Dùng --tools-dir để đổi thư mục hoặc --no-custom-tools để bỏ qua. Tool có confirm: true sẽ hỏi xác nhận qua terminal; --yes-tools bỏ bước hỏi này.

Không phải sandbox: --tool-root giới hạn các tool đọc file, nhưng không ngăn run_command hoặc custom tools truy cập ngoài thư mục. Shell chạy bằng quyền của bạn và không hỏi xác nhận cho mỗi lệnh. Chặn run_command hoặc dùng --no-tools khi không tin nội dung đầu vào.

Paste ảnh

Dán ảnh clipboard trực tiếp vào dòng nhập REPL bằng Ctrl+V.

  1. Cài xclip trên X11 hoặc công cụ wl-paste (gói wl-clipboard) trên Wayland.
  2. Chạy dani-ai chat với model có hỗ trợ ảnh.
  3. Copy ảnh, nhấn Ctrl+V: dòng nhập hiện placeholder như [Ảnh 1].
  4. Nhập câu hỏi về ảnh rồi nhấn Enter để gửi.

Hỗ trợ PNG, JPEG, WebP và GIF; giới hạn dữ liệu clipboard 10 MiB. Nếu clipboard là text, nội dung được chèn tại con trỏ.

Lưu ý: ảnh được gửi đến API và có thể nằm trong phiên đã lưu. Không gửi ảnh chứa thông tin nhạy cảm nếu chưa kiểm tra nhà cung cấp.

Bảo mật

Key của bạn, dữ liệu của bạn — kiểm tra quyền truy cập trước khi bật tools.

  • Đặt quyền 600 cho ai.key; không commit key hoặc file lịch sử vào Git.
  • Nội dung chat, ảnh và kết quả tool được gửi đến nhà cung cấp API đang cấu hình. Ưu tiên HTTPS cho endpoint từ xa.
  • Lịch sử lưu cục bộ có quyền 0600, nhưng không được mã hóa. Xóa hoặc bảo vệ file nếu chứa dữ liệu nhạy cảm.
  • Nội dung file, trang web hoặc đầu ra lệnh có thể chứa chỉ dẫn độc hại (prompt injection). Không coi chúng là chỉ dẫn đáng tin.
  • run_command có thể sửa/xóa file và truy cập mạng. Không chạy dani-ai bằng root; dùng --no-tools khi chỉ cần hỏi đáp.
  • Chỉ cài custom tools đã kiểm tra mã nguồn; tránh --yes-tools với tool chưa tin cậy.

Sự cố

Bắt đầu với dani-ai --show-config để kiểm tra endpoint, model và nguồn cấu hình.

Không tìm thấy lệnh dani-ai

Kiểm tra symlink, quyền thực thi và thêm ~/.local/bin vào PATH. Trong repo có thể chạy trực tiếp ./dani-ai --version.

Thiếu key hoặc lỗi 401 / 403

Kiểm tra dòng đầu của ai.key, key còn hiệu lực và quyền truy cập model. Biến môi trường hoặc flags có thể đang ghi đè file key.

Lỗi 404 hoặc model không tồn tại

Kiểm tra base URL (thường kết thúc bằng /v1, không thêm /chat/completions). Chạy dani-ai models để lấy tên model nếu provider hỗ trợ.

API không hỗ trợ tools hoặc streaming

Thử dani-ai --no-tools --no-stream "Xin chào". Không phải mọi endpoint OpenAI-compatible đều hỗ trợ đầy đủ hai tính năng này.

Timeout hoặc lỗi 429

Tăng thời gian bằng --timeout 120 nếu API chậm. Với lỗi 429, kiểm tra quota, hạn mức request và thử lại sau.

Không paste được ảnh

Kiểm tra xclip / wl-paste, clipboard đang chứa dữ liệu ảnh và terminal không chặn Ctrl+V. Chọn model hỗ trợ ảnh; ảnh quá 10 MiB cần giảm kích thước trước.

Tool không xuất hiện hoặc bị từ chối

Kiểm tra --no-tools, blocklist và thư mục manifest. Custom tool yêu cầu xác nhận sẽ bị từ chối nếu không có terminal để hỏi; chỉ dùng --yes-tools khi đã kiểm tra tool.
