# 1. Executive Plan

Fix strategy has four phases.

Phase 0 builds safety. Add `WM_STATE` publish first. It gives H1 a standard marker for withdraw. Add trapped-error logging. It makes later faults loud.

Phase 1 fixes leaks and focus theft. Fix H1 ghost clients. Fix H4 MapRequest steal. Split H2 focus model into three small tasks.

Phase 2 fixes state sync. Reconcile direct `_NET_WM_STATE` writes (M1). Clear urgency (M2). Fix workspace map order (M3).

Phase 3 fixes polish. Cache atoms and fix timestamp (M5). Clamp floating geometry (L2). Fix reload over-map (L4). Advertise supported hints (L5).

Ordering change from baseline: do M4 publish **before** H1 unmap logic. Reason: audit recommends `WM_STATE` as the disambiguator for H1 races (`AUDIT-X11-20260919-075126.md:66`). H1 fix reads the marker that M4 writes. Test-only H1 repro can land first. Behavior change for H1 must wait for M4.

No task touches correct paths. No task for `DestroyNotify`, transient hints, `ConfigureRequest` reply, `EnterNotify`, `MappingNotify`, fight guard, L1, L3, L6, L7, L8, L9, L10.
